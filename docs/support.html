Common Questions

How the extension works

How do I translate selected text? Select text on a page and use the on-page translate action or the configured `Alt+T` shortcut.
How do I translate a whole page? Use the popup, context menu, or `Alt+W` shortcut to run page translation. Use restore to revert the original text.
Where do I set my API key? Open the extension options page and enter your provider settings there. Different providers require different fields.
Why is translation failing? Check that your selected provider is configured correctly, the API key is valid, and any required region or endpoint field is filled in.
