# Chrome Web Store Listing Copy

## Name

Smart Translator

## Summary / single purpose

Translate selected text, focused inputs, and full web pages on demand using the translation provider chosen by the user.

## Short description

Translate selections, inputs, and full pages with your own API keys and provider choice.

## Detailed description

Smart Translator is a browser extension for people who read, write, and research across languages.

It helps you translate:

- selected text directly on the page
- focused inputs and textareas in place
- full web pages with a restore option
- ad hoc text from the popup

Why people use it:

- Keep translation inside the current tab instead of jumping to another app
- Choose the provider you trust
- Switch between standard translation APIs and AI translation providers
- Keep recent translation history and local cache for repeat lookups
- Use keyboard shortcuts for fast browser-first workflows

Supported providers include:

- Microsoft Azure Translator
- DeepL
- Google Cloud Translation
- LibreTranslate or a compatible self-hosted endpoint
- OpenAI
- Claude
- Gemini
- Doubao
- DeepSeek

How it works:

- Text is only sent for translation when the user explicitly triggers a translation action.
- Provider credentials are entered by the user in the extension options page.
- Translation history and cache are stored in the browser.

## Suggested privacy disclosures

- Website content: yes
- Authentication information: yes, because users can enter provider API keys
- Personal communications or personal info: only if the user explicitly includes them in text they choose to translate
- Data use: providing translation features requested by the user
- Data sale: no
- Advertising use: no
