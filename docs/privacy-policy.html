Smart Translator
Privacy Policy

Translation should stay under the user's control.

Smart Translator only processes text when the user explicitly asks it to translate a selection, an input field, or a page. This policy describes what data may be processed, where it is stored, and when it is sent to third-party translation providers selected by the user.

Last updated: 2026-03-16
Chrome extension
User-initiated translation only

Overview

What Smart Translator does

Smart Translator is a browser extension that helps users translate selected text, focused input fields, and full web pages from inside the browser. The extension allows users to choose a translation provider and enter their own provider credentials where required.

Important Smart Translator does not send text for translation unless the user explicitly triggers a translation action, such as clicking the translate UI, using the popup, or pressing a configured shortcut.

Data We Process

Information the extension may handle

Text selected for translation Includes text selected on a web page, text in an input field, or text pasted into the popup for translation.
Page content the user chooses to translate When the user runs full-page translation, the extension may process translatable text nodes from the current page.
Provider settings Includes API keys, region values, model names, endpoint URLs, and system prompts entered by the user for the selected provider.
Local settings and translation history Includes theme, default engine, hotkeys, recent history, cache entries, and other extension preferences.

How We Use Data

Data is used only to provide translation features

  • To translate text, selections, focused inputs, and web pages at the user's request.
  • To store the user's extension preferences and selected translation provider configuration.
  • To keep recent translation history and cache prior results locally for faster repeated translations.
  • To support optional AI translation prompts and provider-specific settings entered by the user.

Third-Party Providers

When text is sent outside the browser

When the user triggers a translation request, Smart Translator sends the text being translated over HTTPS to the provider currently selected by the user. Depending on the user's settings, this may include providers such as Microsoft Azure Translator, DeepL, Google Cloud Translation, LibreTranslate or a custom LibreTranslate-compatible endpoint, OpenAI, Anthropic, Google Gemini, Doubao, or DeepSeek.

Smart Translator does not control the privacy or retention practices of those third-party providers. Users should review the privacy policy of any provider they choose before sending text to that service.

Storage

Where data is stored

Chrome sync storage Provider settings and extension preferences may be stored in Chrome extension sync storage so they can follow the user's browser profile.
Chrome local storage Translation history and cache entries are stored locally in the browser to improve repeat lookup speed and recent-result access.

Data Sharing

What we do not do

  • We do not sell user data.
  • We do not use user data for advertising or personalized ads.
  • We do not use user data for creditworthiness, lending, or insurance purposes.
  • We do not transfer user data to unrelated third parties for marketing.

User Controls

How users can manage their data

  • Users can change or remove provider settings at any time from the extension options page.
  • Users can clear translation history from the popup.
  • Users can disable or remove the extension at any time through the browser.

Security

How requests are transmitted

Provider requests are sent using HTTPS to the provider endpoint selected by the extension or configured by the user. Users are responsible for verifying the trustworthiness and security of any custom endpoint they choose to use.
