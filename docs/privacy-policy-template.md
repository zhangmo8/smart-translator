# Privacy Policy Template

Last updated: `YYYY-MM-DD`

`Smart Translator` helps users translate selected text, input text, and web page content on demand using a translation provider chosen by the user.

## What this extension collects

The extension may process the following categories of data:

- Text the user selects, pastes, types, or chooses to translate
- Web page text that the user explicitly asks the extension to translate
- Provider configuration entered by the user, such as API keys, model names, endpoint URLs, and region values
- Local extension settings, translation history, and translation cache

## How this extension uses data

The extension uses data only to provide the features requested by the user, including:

- Translating selected text, input text, and full page text
- Saving user preferences such as theme, languages, hotkeys, and default provider
- Caching prior translations and storing recent translation history on the device

## When data is sent to third parties

When the user triggers a translation action, the text being translated is sent over HTTPS to the translation provider currently selected by the user.

Depending on the user's configuration, this may include:

- Google Cloud Translation
- Microsoft Azure Translator
- DeepL
- LibreTranslate or a self-hosted LibreTranslate-compatible endpoint
- OpenAI
- Anthropic
- Google Gemini
- Doubao
- DeepSeek

The extension does not send translation text to a provider unless the user initiates a translation request.

## Where data is stored

- Provider settings and preferences are stored in Chrome extension storage.
- Translation history and cache are stored locally in the browser.

## Data sharing

The extension shares data only with the translation provider selected by the user and only to perform the requested translation.

The extension:

- does not sell user data
- does not use user data for advertising
- does not use user data for creditworthiness or lending decisions
- does not transfer user data for unrelated third-party marketing purposes

## Security

The extension sends provider requests using HTTPS endpoints configured by the extension or the user. Users are responsible for the security and trustworthiness of any custom provider endpoint they configure.

## User controls

Users can:

- change or remove provider credentials in the extension options page
- clear translation history from the popup
- remove the extension at any time
